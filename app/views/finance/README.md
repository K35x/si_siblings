# app/views/finance

## Fungsi

Folder ini berisi tampilan untuk fitur keuangan yang digunakan oleh role owner.

## File yang Ada

- `index.php` : halaman utama keuangan.

## Catatan

- Route utama halaman ini adalah `/finance`.
- Controller yang memuat view ini adalah `FinanceController`.
- CSS halaman keuangan berada di `public/assets/css/finance.css`.
