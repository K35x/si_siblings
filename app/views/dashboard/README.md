# app/views/dashboard

## Fungsi

Folder ini disiapkan untuk tampilan dashboard umum atau tampilan dashboard lama. Saat ini dashboard utama kasir dan owner berada di folder `app/views/layouts/` melalui file `cashier.php` dan `owner.php`.

## File yang Ada

- `index.php` : view dashboard umum.

## Catatan

Jika dashboard dipisah lebih detail di masa depan, view dashboard baru dapat ditempatkan di folder ini agar struktur lebih rapi.
