# app/views/product

## Fungsi

Folder ini berisi tampilan untuk fitur produk yang digunakan oleh role owner.

## File yang Ada

- `index.php` : halaman daftar atau manajemen produk.

## Catatan

- Route utama halaman ini adalah `/products`.
- Controller yang memuat view ini adalah `ProductController`.
- CSS halaman produk berada di `public/assets/css/products.css`.
