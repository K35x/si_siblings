# public/assets/img

## Fungsi

Folder ini menyimpan gambar yang digunakan oleh halaman aplikasi, seperti logo, background, dan gambar header.

## File yang Ada

- `logo.png` : logo aplikasi/brand.
- `background.jpeg` : gambar background.
- `atas.jpeg` : gambar pendukung tampilan.
- `finance-header.jpeg` : gambar header halaman keuangan.
- `image.png` : gambar pendukung lain.

## Catatan

- Panggil gambar dari view atau CSS menggunakan path asset yang sesuai.
- Jangan menyimpan gambar rahasia di folder ini karena dapat diakses publik.
- Gunakan nama file yang jelas jika menambah asset baru.
